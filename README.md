# Amazon SQL Business Analysis

## Project Overview
This project uses SQL to analyze Amazon e-commerce transaction data and solve business-focused analytical problems related to customer behaviour, payment trends, product performance, revenue analysis, and sales growth.

The analysis focuses on extracting actionable business insights using SQL queries, aggregations, customer segmentation techniques, and trend analysis.

## Business Objectives
- Analyze payment behaviour and transaction patterns
- Identify high-performing product categories
- Segment customers based on purchase behaviour
- Evaluate seasonal and monthly sales trends
- Detect data quality issues
- Measure customer loyalty and repeat purchasing behaviour

## SQL Skills Demonstrated
- Joins
- Common Table Expressions (CTEs)
- Window Functions
- Aggregate Functions
- CASE Statements
- Subqueries
- GROUP BY & HAVING
- Date Functions
- Customer Segmentation
- Revenue Analysis

## Key Analysis
- Payment method distribution analysis
- Customer segmentation and loyalty analysis
- Product category revenue analysis
- Monthly and seasonal sales trend analysis
- High-value customer identification
- Payment-wise sales growth tracking
- Data quality validation for product categories

## Key Insights
- Credit cards dominated transaction share across multiple order segments
- Loyal and repeat customers represented strong retention opportunities
- Seasonal demand patterns significantly impacted sales trends
- Premium product categories contributed disproportionately to revenue
- Payment behaviour varied across different customer purchase segments
- Data quality issues were identified in product category naming

## Files Included
- SQL query file
- Business analysis report
- Query explanations and business insights

## Final Conclusion
This project demonstrates how SQL can be used to solve real-world business problems through customer analysis, revenue tracking, segmentation, and trend analysis.

The analysis combines technical SQL querying with business interpretation to generate actionable insights for e-commerce decision-making.
